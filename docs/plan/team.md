## 3. Портреты кандидатов (по ролям)

### Tech Lead
```
Опыт: 5+ лет, full-stack (Python + React)
Должен: построить архитектуру с нуля, собрать команду
Плюсы: опыт MLOps, AI-продуктов, стартапов
Где искать: бывшие Senior из Яндекса, Тинькофф, Ozon
```

### ML Engineer
```
Опыт: 3+ лет, NLP/LLM
Должен: RAG pipeline, vLLM deployment, fine-tuning LLM
Плюсы: опыт с YandexGPT API, GigaChat API, open-source LLM
Где искать: ML-сообщества (t.me/ai_community, t.me/deeplearning)
```

### DevOps
```
Опыт: 3+ лет, обязательно Yandex Cloud
Должен: K8s, Terraform, CI/CD, мониторинг
Плюсы: опыт с GPU-инстансами, vLLM deployment
Где искать: HH / t.me/DevOpsRu
```
