# Vision & Roadmap

> **Проект:** Uniflow — российский AI Super Assistant (аналог Abacus.ai)
> **Статус:** Pre-seed / Active Development
> **Последнее обновление:** Июль 2026

---

## 1. Product Vision

Uniflow — это единый AI-помощник, который объединяет все ведущие языковые модели (YandexGPT, GigaChat, DeepSeek, Qwen, open-source) в один интеллектуальный интерфейс с глубоким RAG по документам и автоматизацией рабочих процессов. Мы делаем ИИ доступным, приватным и управляемым — для профессионалов, которые хотят не переключаться между десятками сервисов, а получать лучший ответ на любой вопрос в одном окне, с контролем над своими данными и возможностью кастомизации под корпоративные стандарты.

## 2. Mission Statement

Сделать мощный ИИ таким же естественным инструментом работы, как электронная почта или IDE — чтобы любой специалист в России мог получить экспертный ответ из любой модели, по своим документам, в безопасной инфраструктуре, не жертвуя приватностью и не платя за десяток подписок.

## 3. Target Audience

| Сегмент | Кто платит | Боль | Готовность платить |
|---|---|---|---|
| **Freelance-профессионалы** | Разработчики, аналитики, копирайтеры, юристы | 5+ подписок на LLM, нет единого окна, тратят время на переключение | 500–1500 ₽/мес |
| **ML-инженеры и Data Scientists** | Сотрудники tech-компаний и AI-стартапов | Нужен быстрый доступ к open-source + API моделям, RAG по внутренней базе знаний | 2000–5000 ₽/мес |
| **SMB (10–100 чел)** | Владельцы бизнеса, операционные директора | Хотят ИИ-помощника для всей команды без найма ML-инженеров | 10 000–50 000 ₽/мес |
| **Enterprise (100+ чел)** | Корпорации (банки, ритейл, госсектор) | Приватность данных, on-premise, соответствие 152-ФЗ, кастомизация | 100 000–500 000 ₽/мес |

**Первичный фокус (Phase 1–2):** Freelance-профессионалы + SMB — быстрее монетизируются, ниже порог входа.
**Вторичный фокус (Phase 3–4):** Enterprise с on-prem и 152-ФЗ.

## 4. Core Value Propositions

1. **Один интерфейс ко всем LLM.** Не нужно 5 подписок и 5 вкладок — выбираешь модель под задачу в едином чате. YandexGPT для генерации, DeepSeek для кода, GigaChat для официальных писем, Qwen для длинных контекстов.

2. **RAG по твоим документам.** Загрузи PDF, Word, Excel, Notion, Confluence — Uniflow найдёт релевантные фрагменты и ответит с опорой на твои данные. Никаких галлюцинаций на пустом контексте.

3. **Приватность по-умолчанию.** Российские серверы (Yandex Cloud), шифрование end-to-end, опция on-premise для Enterprise. Данные не уходят за пределы РФ. Соответствие 152-ФЗ.

4. **Открытое ядро (Open-Core).** Базовая версия — бесплатный open-source CLI/API. Премиум-функции (Agent Builder, AutoML, GenAI Studio) — в подписке. Сообщество расширяет платформу плагинами.

5. **AI Agents без кода.** Phase 2: визуальный Agent Builder — настрой цепочку вызовов моделей, RAG-шаги, внешние API (CRM, почта, телеграм) без единой строки кода.

## 5. Product Principles

1. **Privacy-first, Russia-first.** Все данные — в РФ. Никакого экспорта промптов за границу. Enterprise-клиенты получают on-premise с первого дня Enterprise-фазы. 152-ФЗ — не чекбокс, а архитектурное решение.

2. **Model-agnostic.** Uniflow не привязан к одному провайдеру. Если завтра появится новая SOTA-модель — она добавляется в один клик через LiteLLM-прокси. Пользователь выбирает, мы не навязываем.

3. **Open-Core.** Ядро (базовый чат + RAG + API) — open source под MIT/Apache 2.0. Сообщество может форкать, аудировать код, писать плагины. Монетизация — на Enterprise-функциях и хостинге.

4. **Developer Experience First.** API с SDK на Python, Go, JS. Документация как у Stripe. Терминал (Tauri) и Web UI — одинаково быстрые и отзывчивые.

5. **Offline-first resilience.** Архитектура предполагает работу с перебоями сети: локальный кэш моделей, очередь запросов, graceful degradation. Пользователь не теряет контекст при потере соединения.

## 8. Risks & Mitigations

| # | Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|---|
| **1** | **Регуляторные блокировки (блокировка LLM-провайдеров, новые законы)** | Высокая | Критическое | Ранняя юридическая экспертиза (Phase 0). Архитектура model-agnostic — заблокируют одного провайдера → переключаемся на резервного. On-prem как защита от регуляторных рисков. Держим 3+ провайдера всегда. |
| **2** | **Не набираем критическую массу пользователей (Product-Market Fit Failure)** | Средняя | Критическое | Phase 0: 10+ customer discovery интервью до написания кода. Phase 1: закрытая beta на 50 пользователях с weekly feedback. Итеративный выпуск — не строим "идеальный продукт" в вакууме. Готовность к pivot по результатам beta. |
| **3** | **Отток ключевых разработчиков (маленькая команда — high bus factor)** | Средняя | Высокое | Equity для первых 5 членов команды. Документирование всех решений (ADR). Code review обязателен. Наём Phase 1-2: 2+ человека на ключевую роль. |
| **4** | **Стоимость inference растёт быстрее выручки (negative unit economics)** | Средняя | Высокое | Кэширование ответов (semantic cache). Использование open-source моделей локально (Phase 2: ollama в десктопе). Балансировка дешёвых/дорогих моделей. Enterprise-тариф с фиксированной ценой, а не per-token. |
| **5** | **Конкуренты (YandexGPT-native, GigaChat-native, западные аналоги)** | Высокая | Среднее | Model-agnostic — мы не привязаны к одному вендору. Open-core создаёт сообщество и lock-in на платформе, не на модели. RAG по своим документам — сильный switching cost. Фокус на российском Enterprise с on-prem — ниша, которую западные аналоги не закрывают. |

## Стратегические допущения

1. YandexGPT, GigaChat, DeepSeek, Qwen продолжат работу на РФ-рынке в течение 24 месяцев.
2. Российский Enterprise-сегмент сохранит спрос on-premise решения в рамках импортозамещения.
3. Open-source модели (Llama, Qwen, Mistral) продолжат улучшаться и догонят проприетарные по качеству в базовых задачах.
4. Регуляторное поле не изменится радикально в сторону полного запрета LLM-сервисов.

Если какое-либо из этих допущений нарушается — roadmap пересматривается с фокусом на model-agnostic архитектуру и on-premise как защитный слой.
